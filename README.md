# pureshade.dev

Source for the official Pureshade Labs website.

A single `index.html` with inline CSS and JS. No build step, no dependencies.

## Development

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server
```

Edit `index.html` and refresh.
