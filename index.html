01

OS · Workstation & Server

OROS

A production operating system for workstations and servers, built on Lythos. If a critical service crashes before the stability timer clears, the system reverts and reboots without intervention.

  • 30-second rollback window on every update
  • Capability-secured userspace via Lythos kernel
  • Shell, package manager, IPC bus, all constrained at boot

01

Kernel · Rust · x86-64

Lythos

Capability-based microkernel targeting bare-metal x86_64. Every resource is accessed through an unforgeable kernel-managed token. No ambient authority, no ACL policy engine.

  • Unforgeable capability tokens: if you don't hold it, you don't get access
  • Full stack in around 8,000 lines of Rust
  • Memory, scheduler, APIC, IPC, ELF loader, all built from scratch
